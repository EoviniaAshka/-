巴别塔圣歌 · 字符抄录本（a 测）
================================================================

双击 巴别塔圣歌-字符输入台-a测 文件夹里的 巴别塔圣歌-字符输入台-a测.html
就能用：单文件、离线、不需要联网，字形字体已经包含在文件里。

界面
----------------------------------------------------------------
  · 笔记本界面：摊开的笔记本、书页上的五个族徽页签、
    右侧字形面板、翻页按钮、关闭按钮
  · 书页可以写字：点右侧面板里的字形徽章，就能把对应字形写到书页上
  · 右侧面板会跟着当前语种切换，显示该语族的全部字形

操作
----------------------------------------------------------------
  切换语族         点书页上沿的五个页签 / 点右侧 › 按钮 / 按数字键 1–5
  写字             点右侧字形面板里的徽章，字形会写在光标位置
  光标             点书页任意位置放光标；写字后光标停在新写的字形后面
  分页             书页分左右两页，写满第一页自动接到第二页，写满自动翻页
  空格键            插入空格，用来分隔字形
  退格键            删光标前的字形
  方向键 ← / →      左右翻页
  复制              右下角「复制」：把当前两页内容导出成字形图
                   （透明背景、按内容裁剪），粘贴给别人直接能看到字形
  选中复制          在书页里选中一段，Ctrl+C 也导出成字形图
  清空              清空当前页
  自动保存          存在浏览器里，刷新或关掉再开，内容和上次看的语族都还在

说明
----------------------------------------------------------------
  · 字形和书页内容都保存在浏览器本地，换电脑/换浏览器不会带过去
  · 复制出来的是图片，对方不需要安装字体也能看到
  · 改完字体：双击 a 测 包里的 更新字体.bat，把最新 OTF 嵌进 HTML
    （自动重新打包 zip），之后刷新页面就能看到新字形
