# 巴别塔圣歌 · 字符抄录本 v1.0

《Chants of Sennaar》五语族字符输入台：**单文件、离线、无需联网**，字形字体已内嵌。

支持 信徒 / 战士 / 诗人 / 炼金 / 隐者 五种文字，含各语族数字系统。

## 使用

双击 `巴别塔圣歌-字符输入台-v1.0.html` 即开即用。

## 功能

- 点击右侧面板字符插入书页；空格键插入空格，退格删除
- 数字键 `1`–`5` 或顶部标签切换语族
- 悬停字符显示释义
- 选中书页文字后 `Ctrl+C` 导出字形图（原始尺寸，大小跟随字号）
- 设置页可调字号、颜色、界面语言（中文 / Français / English）
- 炼金术士四位数字形态、连接符与小数点
