双击 巴别塔圣歌-字符输入台-v1.0.html
就能用：单文件、离线、不需要联网，字形字体已经包含在文件里。

界面
----------------------------------------------------------------
  · 笔记本界面：摊开的笔记本、书页上的五个族徽页签、
    右侧字形面板、翻页按钮、关闭按钮
  · 书页可以写字：点右侧面板里的字形徽章，就能把对应字形写到书页上
  · 右侧面板会跟着当前语种切换，显示该语族的全部字形
  · 电脑和手机都能用：电脑上界面随屏幕等比放大（1280~4K）；
    手机竖屏是专门布局（书页占上半屏，底部一排操作键，字形面板可上下滚动）

操作（电脑）
----------------------------------------------------------------
  切换语族         点书页上沿的五个页签 / 点右侧 › 按钮 / 按数字键 1–5
  写字             点右侧字形面板里的徽章，字形会写在光标位置
  光标             点书页任意位置放光标；写字后光标停在新写的字形后面
  换行             Enter
  分页             书页分左右两页，写满第一页自动接到第二页，写满自动翻页
  空格键            插入空格，用来分隔字形
  退格键            删光标前的字形
  方向键 ← / →      左右翻页
  复制字符          底部「复制字符」：把当前两页的字形导出成 .txt 文本
  复制字形图        设置页「复制字形图」：把当前两页导出成一张字形图
                   （透明背景、按内容裁剪），粘贴给别人直接能看到字形
  选中复制          在书页里选中一段，Ctrl+C 也导出成字形图
  清空              清空当前页
  自动保存          存在浏览器里，刷新或关掉再开，内容和上次看的语族都还在
  排序              设置里可切换「词性序」（人→动词→形容词→名词→工具类→场所→其他）
                    或「码位序」

操作（手机）
----------------------------------------------------------------
  轻点字形          插入这个字形
  长按字形          显示释义气泡（不会插入字符）
  底部 ⌫             退格
  底部 ‹ / ›         上一页 / 下一页
  底部 ↵             换行
  底部「复制图」      把当前两页字符导出成一张字形图（复制到剪贴板；
                     浏览器不支持剪贴板时会自动下载 PNG）

说明
----------------------------------------------------------------
  · 字形和书页内容都保存在浏览器本地，换电脑/换浏览器不会带过去
  · 复制出来的是图片，对方不需要安装字体也能看到
  · 改完字体（作者自用）：双击桌面「巴别塔圣歌-维护工具」里的 更新字体.bat，
    会把最新 OTF 嵌进 HTML，并按《塔歌字形表.xlsx》同步词义、重排编号、
    核验码位/字形（有码位但字体里没字形的行会被点名，能自动改正的直接改正），
    最后重新打包 zip；之后刷新页面就能看到新字形
    （维护工具不在发布包里，普通使用不需要）
  · 表里释义写「未知」的行只作记录，不会同步进面板
